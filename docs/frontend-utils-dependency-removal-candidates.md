# Dependency removal candidates for eperusteet-frontend-utils

Scope: `eperusteet-frontend-utils/vue/package.json`. Findings come from static inspection of the shared library, generated clients, configuration, scripts, and the four consumer applications: `eperusteet-ui`, `eperusteet-ylops-ui`, `eperusteet-amosaa-ui`, and `eperusteet-opintopolku`.

This document records candidates from the dependency review. It does not change package manifests. Recheck current usage before applying removals.

## Husky hook notes

Husky is declared in the shared library and all four frontend applications. Discovered configurations are disabled by their filenames:

- Shared library: `vue/.huskyrc_not.js`.
- `eperusteet-ui` and `eperusteet-opintopolku`: `.huskyrc.js.no`.
- `eperusteet-amosaa-ui` and `eperusteet-ylops-ui`: `.huskyrc.js.not`.

Local `.git/hooks` directories still contain scripts generated by Husky v4.3.8, including `husky.sh` and `husky.local.sh`. The inspected wrapper skips task execution when no enabled hook configuration exists. These files are local Git metadata, not tracked project files. Removing a manifest entry and cleaning up local hook remnants are separate concerns; inspect ownership before deleting any hook files.

## Validation

1. Recheck imports, configuration references, and peer requirements for each candidate.
2. Remove a small related group of dependencies at a time. Keep the existing lockfile; do not regenerate it from scratch.
3. Run `yarn install` and review `package.json` and `yarn.lock` diffs for unexpected version changes.
4. Run `yarn explain peer-requirements`, `yarn lint`, and `yarn test --run` in the shared library.
5. Run relevant tests and `yarn build` in affected consumer applications. Check editor tables, charts, exports, and styles when their dependency groups change.

These are static-analysis candidates, not removals verified by clean installations and application builds. Removing a direct declaration does not necessarily remove the package from the lockfile if another dependency still requires it.
